---
name: games-integrating
description: Use this skill every time you do anything with games, the game library, playtime or Playnite.
---

Games are usually played on Windows and managed by Playnite in `~/data/software/playnite`.
Read its state with `scripts/playnite.py ~/data/software/playnite/library/<collection>.db`, which prints one JSON document per line.
For new games prefer the portable version in `~/data/software/games` (`X:\software\games` on Windows), synced by Google Drive. Otherwise install normally.
