# dotfiles

- Terminal centric.
- Interchangeable harnesses.
- No vendor-locks.
- Self-hosted services and custom tools.
- Public, but secret stuff gitignored.

- `setup.sh` installs everything on a fresh Ubuntu and symlinks this repo into place.
- `dot/` - dot configs symlinked into home dir
- `config/` - configs for ai agents and other tools
- `skills/` - agents' skills
- `services/` - systemd user services to be runned on the machine
- `windows/` - scripts for the Windows side of the dual boot
